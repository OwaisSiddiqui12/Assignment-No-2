# Phones.pk — E-Commerce Website

A responsive multi-page e-commerce website for buying mobile phones, electronics, appliances, and accessories online — built as a SMIT (Saylani Mass IT Training) class assignment.

## 📄 Pages

| Page | Description |
|------|-------------|
| `index.html` | Home — hero carousel, featured mobiles, brands, product cards |
| `about.html` | About — mission, product categories, delivery stats across Pakistan |
| `products.html` | Products — full product listing with brand showcase |
| `services.html` | Services — delivery, COD, warranty, returns, support & repairs |
| `contact.html` | Contact — WhatsApp, LinkedIn, Facebook and call details |

## 🛠️ Technologies Used

- **HTML5** — semantic markup
- **Bootstrap 6 (alpha)** — responsive grid, navbar, carousel, drawer & utility classes
- **Custom CSS** — branding, hover effects & custom theme (`#0F172A` navy + orange)
- **Bootstrap Icons** — social & service icons
- **Google Fonts** — Poppins & Boldonse

## ✨ Features

- Fully responsive layout (desktop & mobile drawer navigation)
- Auto-playing image carousel
- Product cards with hover effects
- Delivery stats with animated-style counters
- Workable social & contact links (WhatsApp, call, email)
- Consistent theme across all 5 pages

## 🚀 How to Run

Just open `index.html` in any browser — no build step or server required.
